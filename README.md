# 마음쉼 심리상담센터 홈페이지 (초안)

순수 HTML/CSS/JS로 만든 1페이지 홈페이지입니다. 별도 빌드 과정 없이 파일을 열거나 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

## 로컬에서 확인하기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 바로 열어도 됩니다.

## 채워야 할 플레이스홀더

`index.html` 안에서 `[플레이스홀더]`로 표시된 부분을 실제 내용으로 교체하세요.

- 센터 이름 / 슬로건 (현재 "마음쉼 심리상담센터"는 예시 이름입니다)
- 소개글, 대표 상담사 정보, 자격/경력
- 대표 이미지 (`.image-placeholder` 영역을 실제 사진으로 교체)
- 프로그램 목록 및 가격
- 주소, 전화번호, 이메일, 영업시간
- 지도 (`.location-map`의 placeholder를 카카오맵/네이버맵 embed 또는 이미지로 교체)

## 문의 폼 이메일 주소 변경

`script.js`의 `CENTER_EMAIL` 상수를 실제 상담센터 이메일 주소로 교체하세요.

```js
const CENTER_EMAIL = "contact@example.com";
```

현재 폼은 `mailto:` 링크를 열어 사용자의 이메일 앱으로 문의 내용을 전달하는 방식입니다. 추후 실제 서버나
Formspree 같은 폼 서비스와 연동하면 사용자가 이메일 앱 없이도 바로 제출할 수 있습니다.

## 배포

정적 파일만으로 구성되어 있어 아래 어떤 방식으로도 바로 배포할 수 있습니다.

- **Vercel / Netlify**: 저장소를 연결하면 별도 빌드 설정 없이 자동 배포됩니다.
- **GitHub Pages**: 저장소 설정에서 Pages를 활성화하고 브랜치/루트를 지정하면 됩니다.
